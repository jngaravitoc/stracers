*********
Tutorials
*********

The first two tutorials use a toy halo sampled with `stracers.halos`, so they
need no simulation data and are run when the documentation is built. The
third uses a sample of a Milky Way simulation, which is not public: it is
shown as it was run (see ``tests/make_sim_sample.py`` to make the sample). They
are in the ``tutorials/`` folder of the repository.
